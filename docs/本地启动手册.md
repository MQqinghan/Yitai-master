# 本地启动手册（2026-09-28）

> 前置：本机已装 Docker Desktop + IntelliJ IDEA Community（免费，Java 后端用它；PyCharm 是 Python IDE 不支持 Maven/Java 运行）+ Node(>=20)。
> JDK 17 与 Maven **都不用单独装**：JDK 在 IDEA 里一键下载（见 2.2），Maven 用 IDEA 内置的。

## 1. 起中间件（一键）

```bash
# 在仓库根目录（Yitai-master/）执行
docker compose up -d
```

| 容器 | 端口 | 说明 |
|---|---|---|
| yitai-mysql | 3306 | root/root，库 `yitai_mall`，**首启自动建表+灌压测数据**（500+SKU/100+用户） |
| yitai-redis | 6379 | 无密码 |
| yitai-nacos | 8848 / 9848 | **v2.4.3**，单机 + **MySQL 持久化**（库 `nacos_config`）。⚠️ 勿降回 v2.2.3：其镜像内 JDK8 过老，在 Windows Docker Desktop（cgroup v2）下启动必 NPE 崩溃循环。控制台 http://localhost:8848/nacos（nacos/nacos） |
| yitai-es | 9200 | 7.17.26 + IK 中文分词，单节点 |
| yitai-minio | 9000 / 9001 | 对象存储（manager 上传图片用），控制台 http://localhost:9001（minioadmin/minioadmin） |

> **建桶（一次性）**：打开 http://localhost:9001 登录后 Create Bucket → 名称 `1-bucket`；或命令行：
> `docker run --rm --network yitai_default minio/mc sh -c "mc alias set yitai http://minio:9000 minioadmin minioadmin && mc mb --ignore-existing yitai/1-bucket"`

验证：`docker compose ps` 四个容器 Up；`curl http://localhost:9200` 返回版本 7.17.26。

> ⚠️ MySQL 首次初始化需要 1-2 分钟（灌数据），日志看到 "ready for connections" 再起服务。
> 若 02 压测数据导入报错：`docker logs yitai-mysql | grep ERROR`，把报错表发给小清算 DDL 差异。

## 2. 起后端（IntelliJ IDEA Community）

> 为什么不是 PyCharm / CodeBuddy：PyCharm 是 Python IDE，不支持 Maven 多模块与 Java 运行（所以看不到启动键）；CodeBuddy 是 AI 编码**插件**（装在 IDEA/PyCharm/VS Code 之上的 AI 层），不承担 Java 运行环境。AI 编码由小清负责，本机只需装 IDEA。

### 2.1 装 IDEA（一次性，免费）

1. 下载 IDEA Community：https://www.jetbrains.com/idea/download/?section=windows （页面往下拉，选 **Community Edition** 的 `.exe`，别下错成 Ultimate 付费版）。
2. 安装一路 Next（建议勾选 Create Desktop Shortcut），完成后启动。

### 2.2 打开项目 + 下载 JDK 17（JDK/Maven 都不用手动装）

1. IDEA → **Open** → 选 `D:\xiangmu\Yitai\Yitai-master\backend` 目录（IDEA 识别到 pom.xml 会以 Maven 项目打开）→ Trust Project。
2. **下载 JDK 17**：File → Project Structure → Project → SDK 下拉选 **Add SDK → Download JDK…** → Version **17**、Vendor **Eclipse Temurin (AdoptOpenJDK HotSpot) 17.0.20.1**（列表里带这个全名的那个）→ Download → OK。
   > ⚠️ **若 Temurin 下载超时**（它托管在 GitHub，国内常断）：Vendor 改选 **Microsoft OpenJDK 17.0.20.1** 再 Download——走微软 CDN，国内快，与 Temurin 完全等价；或从清华镜像手动下 msi 安装后用 **Add SDK → JDK** 指向安装目录：
   > `https://mirrors.tuna.tsinghua.edu.cn/Adoptium/17/jdk/x64/windows/OpenJDK17U-jdk_x64_windows_hotspot_17.0.20.1_1.msi`
3. 等右下角 Maven 依赖下载/索引完成（首次几分钟；进度条消失、无红色报错即就绪）。

### 2.3 依次启动 8 个服务

依次打开以下 8 个启动类，点 `main` 方法左侧绿色 ▶ 运行（第一次运行会自动生成 Run Configuration）：

| 顺序 | 启动类 | 路径（backend/ 下） | 端口 |
|---|---|---|---|
| 1 | `UserApplication` | `service\service-user\src\main\java\com\yitai\user\UserApplication.java` | 8512 |
| 2 | `ProductApplication` | `service\service-product\src\main\java\com\yitai\product\ProductApplication.java` | 8511 |
| 3 | `CartApplication` | `service\service-cart\src\main\java\com\yitai\cart\CartApplication.java` | 8513 |
| 4 | `OrderApplication` | `service\service-order\src\main\java\com\yitai\order\OrderApplication.java` | 8514 |
| 5 | `PayApplication` | `service\service-pay\src\main\java\com\yitai\pay\PayApplication.java` | 8515 |
| 6 | `ManagerApplication` | `manager\src\main\java\com\yitai\manager\ManagerApplication.java` | 8501 |
| 7 | `GatewayApplication` | `server-gateway\src\main\java\com\yitai\gateway\GatewayApplication.java` | 8500 |
| 8 | `AiApplication` | `service\service-ai\src\main\java\com\yitai\ai\AiApplication.java` | 8600 |

> 业务服务先起（快速暴露 DB/Redis/MinIO 问题），网关最后起；AI 随时。
> 每个服务控制台出现 `Started XxxApplication in ...` 即成功。

3. 验证：Nacos 控制台 http://localhost:8848/nacos（nacos/nacos）→「服务列表」，应能看到 8 个服务（server-gateway / server-manager / service-user / service-product / service-cart / service-order / service-pay / service-ai）。

> 数据库连接约定（已改好）：`localhost:3306/yitai_mall`，root/root；Nacos 配置中心已改为 `optional:` 导入，本地不需要在 Nacos 建任何配置。

## 3. ES 索引初始化（商品搜索）

商品搜索走 ES（SearchServiceImpl），需把 DB 数据同步进 ES 一次：
- 调 `service-product` 的诊断/同步接口（`EsDiagnosticController` 有索引检查；`DataSyncService` 做 DB→ES bulk 同步）——具体接口路径启动后看 swagger/日志确认，或 `curl localhost:8511/`+路由前缀探测。

## 4. 起前端

```bash
# 后台管理
cd admin-web && npm install && npm run dev
# C 端门户
cd portal-web && npm install && npm run dev
```

## 5. AI 模块（service-ai）

- **默认带真实 LLM**：本机 `application-local.yml`（已被 .gitignore 排除）配置了 DashScope `qwen-flash`（与 RAG_文旅 / auto-jianli 同一把 key），`ai.provider=openai`。
- **clone 即跑模式**：别人 clone 后没有 local 文件 → 自动回退 `AI_API_KEY=placeholder + provider=mock`（MockAgent 用规则+真实商品数据演示），不配 key 也能跑通全流程。
- 想换供应商：改 `AI_BASE_URL` / `AI_MODEL` 环境变量即可（智谱：`https://open.bigmodel.cn/api/paas/v4` + `glm-4-flash-250414`；DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat`）。

## 6. 常见问题

| 症状 | 处理 |
|---|---|
| 服务起不来报 Nacos 连接失败 | 先 `docker compose up -d` 等 nacos 健康（控制台能打开） |
| MySQL 连接拒绝 | 等首启初始化完成（日志 "ready for connections"） |
| 搜索报 ES 相关错误 | `docker compose up -d elasticsearch` + 重做第 3 步数据同步 |
| 时间差 8 小时 | MySQL 容器已带 `--default-time-zone=+08:00`，勿删 |
