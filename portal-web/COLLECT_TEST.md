## 测试步骤

### 前置条件
1. ✅ 确保后端服务已启动（端口 8511）

### 测试场景

#### 场景 1: 商品详情页 - 收藏商品
1. 访问任意商品详情页（如：`http://localhost:8088/#/detail/1`）
2. 点击收藏按钮（星形图标）
3. **预期结果**：
   - 显示"收藏成功"提示
   - 星形图标变为实心
   - 后端数据库 user_collect 表新增记录

#### 场景 2: 商品详情页 - 取消收藏
1. 在已收藏的商品详情页
2. 再次点击收藏按钮
3. **预期结果**：
   - 显示"已取消收藏"提示
   - 星形图标变为空心
   - 后端数据库对应记录的 is_deleted 变为 1

#### 场景 3: 查看收藏列表
1. 进入"我的收藏"页面（用户中心 -> 我的收藏）
2. **预期结果**：
   - 显示所有已收藏的商品列表
   - 每个商品显示：图片、名称、售价、店铺名称
   - 顶部显示收藏总数

#### 场景 4: 收藏列表 - 取消收藏
1. 在收藏列表页面
2. 点击某个商品的"取消收藏"按钮
3. **预期结果**：
   - 显示"已取消收藏"提示
   - 该商品从列表中消失
   - 收藏总数减 1
   - 后端数据库对应记录的 is_deleted 变为 1

#### 场景 5: 重复收藏
1. 对同一商品多次点击收藏
2. **预期结果**：
   - 后端不会创建重复记录
   - 前端显示已收藏状态

#### 场景 6: 未登录用户
1. 退出登录
2. 尝试收藏商品
3. **预期结果**：
   - 请求失败（401 或相关业务错误）
   - 显示错误提示

## 调试技巧

### 浏览器控制台
打开浏览器开发者工具（F12），查看：
- **Network 标签**：查看 API 请求和响应
  - 请求 URL：`/api/product/collect/*`
  - 请求方法：POST / DELETE / GET
  - 请求头：包含 `token` 字段
  - 响应数据：检查返回的 code 和 data

- **Console 标签**：查看日志和错误信息

### 常见问题

#### 问题 1: 请求失败 - 401 Unauthorized
**原因**：用户未登录或 token 过期
**解决**：重新登录获取新 token

#### 问题 2: 请求失败 - 404 Not Found
**原因**：后端服务未启动或路径配置错误
**解决**：
- 检查后端服务是否在 8511 端口运行
- 检查 vite.config.ts 中的代理配置

#### 问题 3: 收藏列表为空
**原因**：数据库中无收藏记录
**解决**：先在商品详情页收藏几个商品

#### 问题 4: CORS 跨域错误
**原因**：后端未配置跨域
**解决**：检查后端是否启用 CORS（Spring Boot 通常已配置）

## 数据库验证

可以通过 SQL 查询验证收藏数据：

```sql
-- 查看某用户的收藏记录
SELECT * FROM user_collect WHERE user_id = ? AND is_deleted = 0;

-- 查看收藏的商品详情（需要关联查询）
SELECT uc.*, ps.sku_name, ps.sale_price, ps.thumb_img
FROM user_collect uc
LEFT JOIN product_sku ps ON uc.sku_id = ps.id
WHERE uc.user_id = ? AND uc.is_deleted = 0;
```
